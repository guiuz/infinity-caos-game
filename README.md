# Infinity Caos

Jogo arcade top-down para navegador, construído para explorar renderização 2D, interação em tempo real e uma interface de alta intensidade visual.

[▶ Jogar a demo](https://infinitycaos.com/)

## Tecnologias

- HTML5 Canvas 2D e JavaScript puro
- Tailwind CSS
- Firebase Authentication e Cloud Firestore
- Web Audio API

## Destaques técnicos

- Arena dinâmica, movimentação, colisões e partículas renderizadas no Canvas.
- Inimigos com comportamentos distintos, chefes, obstáculos e power-ups.
- Controles para desktop e mobile, com HUD responsivo.
- Ranking persistente integrado ao Firebase.

## Executar localmente

O jogo não possui etapa de compilação versionada. Clone o repositório e abra `index.html` em um navegador:

```bash
git clone https://github.com/guiuz/infinity-caos-game.git
cd infinity-caos-game
```

Para testar com os recursos remotos e integrações do navegador, sirva a pasta por um servidor HTTP local e acesse `index.html`.
